# FlowLedger Landing Page

Public marketing landing page for [FlowLedger](https://flowledger.razs.dev), a
web-first personal finance platform. This is a standalone, static site with no
backend — its only job is to explain the product and send visitors to the
app's login/register pages.

See [CLAUDE.md](./CLAUDE.md) for project scope, conventions, and the
English-only / TSDoc requirements that apply to this codebase.

## Development

```bash
npm install
npm run dev        # start the dev server
npm run build       # type-check and build for production
npm run typecheck   # type-check only
npm run lint        # lint
```
